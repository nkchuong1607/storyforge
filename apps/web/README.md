# StoryForge Web

Next.js App Router frontend (author UI).

## Status

Bootstrap placeholder page only. Chapter Editor and Continuity Gate are Phase 4.

## Develop

```bash
cd apps/web
npm install
npm run dev
```

Or from repo root: `make web-dev`

## UI Skills

Before building UI, install external skills — see `docs/agent-setup.md` and `skills/storyforge-ui-external/`.
